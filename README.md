# Job Search Dashboard
A no-build, no-serverside, local browser app for your job search. Free to use and iterate on. Good luck!

> [!CAUTION]
> Your data is stored in the browser. If you clear browsing data you will lose your data in this app. There is a built-in reminder mechanism to backup your data--please use the Export function to back up your data!

## Install
git clone https://github.com/mjennings3/job-search-dashboard.git
cd job-search-dashboard
open index.html

## Features
- Dashboard to see your activity at a glance.
- Kanban board to keep track of your leads and applied roles.
- Asset and document management for your websites, profiles, applications, and cover letters.
- Contacts per application to keep track of who you have talked to.
- Reminders based on dates you set for follow-up, interviews, due applications, etc.
- LinkedIn URL generator with search params to help you find who to chat-up on LinkedIn faster.
- Portable via Import/Export JSON.
- Quick Add feature for listings so you can fill in details later.
